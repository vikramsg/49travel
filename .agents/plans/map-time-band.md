# Plan: travel-time range on the map tab

Status: agreed, implemented. **Once implementation starts, do not edit this file** — record all changes in
`.agents/implementation-notes/map-time-band.md` instead.

## Goal

Let the map answer "*from city X, what can I reach by train in a travel-time range?*" instead of only
"*…within Y hours?*". The map gains a lower bound as well as an upper bound, and the lower bound defaults
to 0 h so the default view is unchanged.

## Answers that fixed the shape

| Question | Answer |
|---|---|
| Unit | whole hours |
| Control | one range slider, **plus** a form to type the minimum and maximum for exact values |
| The origin when the range starts above 0 | stays on the map |
| Wording | "between X h and Y h" |
| Delivery | a plain PR off `main`; the previous stack is merged |
